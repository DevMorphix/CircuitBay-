# PART E — GLOBAL UI RULES

- **Nav (main site):** Shop · Learn · Community · For Educators · About · `Start Building` button.
- **Buttons:** Primary = solid `#3F7DDE`, white text. Secondary = outline. Rounded 8–12px.
- **Cards:** white, soft shadow, 12px radius; hover lifts slightly and shows a blue circuit-trace border glow.
- **Section rhythm:** dark → light → dark so pages breathe (per the original plan).
- **Icons:** one consistent line-icon set in logo blue.
- **Motion:** subtle. Circuit-trace lines animate on scroll/hover. Respect `prefers-reduced-motion`.
- **Photography:** real workshop and student photos, not stock.
- **Mobile:** single-column stacks, sticky cart button on shop, hamburger nav.
